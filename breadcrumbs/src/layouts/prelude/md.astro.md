# `src/layouts/prelude/md.astro`

## 2026-09-18 — the rail slug stopped naming the page

It used to lead with the page's own path, which is the one thing a reader
already knows — they are looking at it, and the title is set at the top of the
page in the largest type on it. What is left is what the page cannot tell you
by being read: when it was published, when it was last edited if it has been,
and which revision this copy was built from.

The segments are joined with `·` rather than run together, and each optional
one carries a word — `ed`, `rev`. Set upright in a vertical column, a bare dot
between two blank slots reads as a separator; without the spaces it reads as a
full stop at the end of the date before it.
