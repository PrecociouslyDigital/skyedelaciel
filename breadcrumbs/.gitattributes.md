# .gitattributes

## 2026-10-06 — LF in the working tree, everywhere

With `core.autocrlf=true`, Windows checkouts got CRLF. That broke three things
at once: prettier's `--check` flagged 52 files, `logo.test.ts` failed to parse
`tools/logo.mjs` (a shebang line ending in `\r`), and the same test compared
the generator's LF output against a CRLF `public/logo.svg`. The index was
already all LF; `* text=auto eol=lf` makes the working tree match it whatever
the local git config says. `.prettierrc` also takes `endOfLine: auto`, so a
file checked out before this still passes.
