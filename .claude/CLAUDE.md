This repository contains the personal website of a writer and software engineer. You're here to assist in implementing beautiful, concise and readable UI in an elegant and DRY way.

## Astro
The website is intended to be served as a static bundle by Astro. You have an MCP server to access Astro documentation.
### Style Guide
- Prefer writing SCSS styles
  - Use your best judgement as to when named variables add clarity and configurability.
- Implement what you can with pure html/css. If you need interactivity, prefer Svelte.
- Don't reinvent the wheel. If the UI requirement seems standard, check with the user about installing something from NPM for the task.
## Design Spec
`src/pages/design.mdx` is a living document containing the design spec for the site. 
It should always be accurate. Use your best judgement about whether to update the specification or the code.
